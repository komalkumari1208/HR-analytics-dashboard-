# HR Analytics Dashboard 📊

## About the Project

I created this HR Analytics Dashboard using Power BI to understand employee data and look at different patterns related to employee attrition.
The dashboard makes it easier to see important HR information instead of going through a large dataset manually.

## What the Dashboard Shows

### Overview
- Total number of employees
- Active employees
- Attrition rate
- Average salary
- Attrition by department
- Gender distribution
- Headcount by job role

### Deep Dive
- Attrition by age group
- Attrition by income band
- Average years spent at the company by department
- Attrition by job level

## Tools Used

- Power BI
- DAX
- Data Analysis
- Data Visualization

## What I Learned

Through this project, I practiced working with employee data, creating DAX measures, building interactive visuals, and presenting data in a simple and useful way.

The main goal of this project is to turn raw HR data into simple insights that can help understand workforce trends and employee attrition.
